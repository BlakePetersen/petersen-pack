# Client Galleries - Private Photo Delivery

Client Galleries are private, password-protected photo delivery spaces where you share final edited images with your clients after a session.

## What is a Client Gallery?

Think of Client Galleries as private online albums where:
- Only the assigned client can view photos (after logging in)
- You upload the final edited images from a session
- Clients can mark favorites, download images, and view their photos
- Galleries can have expiration dates
- Optional additional password protection

**This is different from your public Portfolio**, which showcases your work to all visitors.

## Creating a Client Gallery

### Step-by-Step

1. **Click "Client Galleries"** in the sidebar

2. **Click "Create New Gallery"** button

3. **Fill Out Gallery Information**:

   **Gallery Title** (Required)
   - Name that identifies the client and session
   - Example: "Johnson Family - Fall 2024"
   - Client sees this title when viewing gallery

   **Client Email** (Required)
   - Email address of your client
   - Used to create their account if they don't have one
   - They'll use this email to login

   **Client Name** (Required)
   - Client's full name
   - Example: "Sarah Johnson"

   **Expiration Date** (Optional)
   - When gallery becomes inaccessible
   - Example: 90 days from delivery
   - Client sees countdown timer
   - You can extend this later if needed

   **Gallery Password** (Optional)
   - Additional password protection
   - Different from client login password
   - Adds extra security layer
   - Client must enter this after logging in

4. **Click "Create Gallery"**
   - Client account created automatically (if new)
   - Unique gallery link generated
   - You can now upload photos

### What Happens When You Create a Gallery

**For New Clients**:
- User account created automatically with the email provided
- Temporary password generated (they use the gallery link, not password)
- Client logs in with their email

**Gallery Link**:
- Unique URL like: `yourdomain.com/client/johnson-family-fall-2024-abc123`
- Share this link with your client
- Slug is unique and hard to guess

## Uploading Photos to Client Gallery

### Adding Images

1. **Go to Client Galleries** page
2. **Click on the gallery** you want to add photos to
3. **Click "Upload Images"** or similar button
4. **Select Images**:
   - Drag and drop multiple files
   - OR click to browse and select
5. **Wait for Upload**:
   - Images process one by one
   - Same optimization as portfolio images
6. **View Uploaded Images**:
   - See all images in the gallery
   - Reorder if needed

### How Many Photos to Upload?

- Deliver the full session as promised to client
- Typically 50-200+ images depending on session type
- All final edited images client paid for

### Best Practices

**Image Quality**:
- Upload only final, fully edited images
- Full resolution (system optimizes automatically)
- Color corrected and retouched

**Organization**:
- Use sort order to create a narrative flow
- Start strong with a great image
- Vary shot types (wide, close-up, details)

**Timing**:
- Upload all images before sharing link
- OR let client know more photos coming soon

## Sharing Gallery with Client

### Getting the Gallery Link

1. Go to **Client Galleries**
2. Find the gallery you created
3. **Copy the gallery URL** shown
   - Example: `https://yoursite.com/client/johnson-family-abc123`

### How to Share

**Via Email** (Recommended):
```
Hi Sarah,

Your photos are ready!

View your gallery here:
https://yoursite.com/client/johnson-family-abc123

Login with your email: sarah@example.com

[If password protected, include:]
Gallery password: your-chosen-password

Your gallery expires on: January 15, 2025

Instructions:
- Click any image to view full size
- Mark your favorites with the heart icon
- Download images using the download button
- Filter to show only favorites

Enjoy your beautiful photos!

Best,
[Your Name]
```

**Include**:
- Direct link to gallery
- Their login email
- Gallery password (if you set one)
- Expiration date
- Brief instructions

## Client Experience

### How Clients Access Their Gallery

1. **Click the gallery link** you provided
2. **Login** (if not already logged in)
   - Enter their email
   - Enter their account password (if first time, they may need to create one)
3. **Enter gallery password** (if you set one)
4. **View their photos**

### What Clients Can Do

**View Photos**:
- Browse all images in grid layout
- Click any image to view full size with lightbox
- Navigate with arrow keys or on-screen controls
- Zoom and pan on mobile

**Mark Favorites**:
- Click heart icon on any image
- Useful for selecting prints or albums
- You can see which images they favorited

**Download Images**:
- Download button on each image
- Downloads high-quality version
- System tracks downloads (you can see stats)

**Filter**:
- Toggle to show only favorited images
- Makes it easy to review their selections

**See Expiration**:
- Countdown shows time remaining
- Encourages timely downloads

### What Clients Cannot Do

- Cannot delete images
- Cannot upload images
- Cannot edit images
- Cannot share gallery publicly (private link only)

## Managing Existing Galleries

### Viewing Gallery Details

1. Go to **Client Galleries**
2. **Click on a gallery** to view:
   - All uploaded images
   - Client information
   - Expiration date
   - Gallery statistics

### Extending Expiration Date

If a client needs more time:

1. **Edit the gallery**
2. **Update "Expiration Date"** field
3. **Save changes**
4. Notify client of extension

### Adding More Photos

You can always add more photos:

1. **Open the gallery**
2. **Click "Upload Images"**
3. **Add new photos**
4. Client sees them immediately

### Removing Photos

If you need to remove an image:

1. **Find the image** in the gallery
2. **Click delete** button
3. **Confirm deletion**
4. Image removed immediately

## Expired Galleries

### What Happens When a Gallery Expires?

- Client can no longer access the gallery
- They see "This gallery has expired" message
- Photos are still in your system (not deleted)
- You can still access as admin

### Restoring Access

To restore access to an expired gallery:

1. **Edit the gallery**
2. **Set new expiration date** (future date)
3. **Save changes**
4. **Notify client** that access is restored

## Gallery Statistics

### What You Can Track

- **Favorite Count**: How many images client favorited
- **Download Count**: Which images were downloaded
- **Last Accessed**: When client last viewed gallery

### Using This Information

**Favorites**:
- See which images client loves most
- Use for print orders or album design
- Understand client preferences for future sessions

**Downloads**:
- Confirm client received all photos
- Follow up if they haven't downloaded

## Security & Privacy

### Access Control

**Who Can View**:
- Assigned client (must login)
- You (admin account)
- No one else

**Password Protection**:
- Account password (required login)
- Gallery password (optional extra layer)
- Unique, hard-to-guess URLs

### Best Practices

**Expiration Dates**:
- Set reasonable timeframes (60-90 days typical)
- Gives urgency for downloads
- Prevents indefinite hosting

**Gallery Passwords**:
- Use for extra sensitive sessions
- Choose secure passwords
- Share separately from gallery link

**Client Communication**:
- Explain expiration clearly
- Remind about backups before expiry
- Offer extensions if needed

## Troubleshooting Client Issues

### "I can't access my gallery"

**Possible causes**:
1. **Gallery expired**: Check expiration date, extend if needed
2. **Wrong email**: Verify they're using correct login email
3. **Wrong password**: Client may need password reset
4. **Gallery password**: Ensure they entered gallery password (if set)

### "I can't download images"

**Solutions**:
- Try different browser
- Check internet connection
- Try right-click > Save Image As (alternative method)
- Provide images via alternative method if technical issues persist

### "Images are loading slowly"

**Causes**:
- Client's internet connection speed
- Large number of images in gallery
- Mobile data connection

**Solutions**:
- Recommend WiFi connection
- Download in batches
- Be patient with loading

## Best Practices

### Gallery Creation

**Naming**:
- Include client name and session type
- Add date or season
- Examples:
  - "Martinez Wedding - June 2024"
  - "Baby Emma - Newborn Session"
  - "Thompson Family Portraits"

**Expiration**:
- Standard: 60-90 days
- Weddings: 90-120 days (more images, more time needed)
- Shorter: 30 days with extension option
- Communicate clearly in contract

**Password Protection**:
- Use for very private sessions
- Wedding galleries (family privacy)
- Boudoir or sensitive content
- Corporate/commercial (NDA situations)

### Communication

**Initial Delivery**:
- Email gallery link promptly
- Include all access information
- Provide brief instructions
- Set expectations (expiration, downloads)

**Follow-Up**:
- Check if they've accessed gallery
- Answer questions promptly
- Remind before expiration (1 week warning)

**Professional Touch**:
- Thank them for their business
- Invite them to leave review
- Ask permission to use favorites in portfolio
- Offer print/album services

### Organization

**Keep Track**:
- Note which galleries are active
- Set reminders for expirations
- Archive old galleries (mental note or system)

**Regular Cleanup**:
- After expiration + grace period, consider removing
- Keep portfolio favorites
- Maintain client relationship history

## Common Questions

**Q: Can I reuse a gallery for the same client?**
A: Create a new gallery for each session to keep them organized. You can have multiple galleries per client.

**Q: Can clients share their gallery link?**
A: The link works for anyone who has it, but they still need login credentials. Remind clients galleries are for personal use.

**Q: What if a client wants their gallery indefinitely?**
A: You can set a far-future expiration date, but encourage personal backups. Explain hosting costs if needed.

**Q: Can I see which photos clients favorited?**
A: Yes! View the gallery as admin to see favorite counts and which images were marked.

**Q: What format are downloads?**
A: High-quality WebP format (optimized for web). Original format if needed can be provided separately.

**Q: Can I remove a client's access?**
A: Yes, by setting expiration to a past date or deleting the gallery entirely.

**Q: How many galleries can I create?**
A: No strict limit - create as many as you need for your clients.

**Q: Can clients comment on photos?**
A: Not currently. Favorites are the main feedback mechanism. Discuss selections via email/phone.
