# Managing Your Portfolio

Your portfolio is the heart of your website, showcasing your photography work to potential clients.

## Understanding Galleries

A **gallery** is a collection of images from a specific shoot or category.

**Examples**:
- "Summer Weddings 2024"
- "Family Portraits"
- "Commercial Work"
- "Maternity Sessions"

Each gallery has:
- **Title**: Display name (e.g., "Beach Wedding Collection")
- **Slug**: URL-friendly version (e.g., "beach-wedding-collection")
- **Description**: Optional text about the gallery
- **Shoot Type**: Category (Wedding, Portrait, Commercial, etc.)
- **Featured**: Whether to show on homepage
- **Sort Order**: Display order (lower numbers first)
- **Cover Image**: Optional main image for the gallery card

## Creating a New Gallery

### Step-by-Step

1. **Navigate to Galleries**
   - Click **"Galleries"** in the left sidebar

2. **Click "Create New Gallery"**
   - Button at the top of the gallery list

3. **Fill Out Gallery Information**

   **Title** (Required)
   - Enter a descriptive name
   - Example: "Sunset Wedding - Sarah & Mike"

   **Slug** (Auto-generated)
   - URL-friendly version of title
   - Example: "sunset-wedding-sarah-mike"
   - Can be edited if needed
   - Must be unique

   **Description** (Optional)
   - Add context about the shoot
   - Example: "A beautiful beachside ceremony at golden hour"

   **Shoot Type** (Optional)
   - Select category: Wedding, Portrait, Family, Maternity, Commercial, etc.
   - Helps clients filter your portfolio

   **Featured** (Checkbox)
   - Check to display on homepage
   - Limit to your best 3-6 galleries

   **Sort Order** (Number)
   - Lower numbers appear first
   - Example: 0, 10, 20, 30
   - Leave gaps for easy re-ordering later

4. **Click "Create Gallery"**
   - Gallery is created and you can start uploading images

### Best Practices

**Naming Galleries**:
- Be specific and descriptive
- Include shoot type or theme
- Include year for time-based collections
- Examples:
  - ✅ "Rustic Barn Wedding - Fall 2024"
  - ✅ "Newborn Photography Collection"
  - ❌ "Gallery 1"
  - ❌ "Photos"

**Organizing Galleries**:
- Use sort order to highlight your best work
- Feature your most impressive galleries
- Update featured galleries seasonally
- Keep total galleries manageable (10-20)

**Descriptions**:
- Keep it brief (2-3 sentences)
- Mention unique aspects of the shoot
- Include location or season if relevant

## Editing a Gallery

### Updating Gallery Details

1. **Go to Galleries** in sidebar
2. **Find the gallery** you want to edit
3. **Click the gallery name** or edit icon
4. **Update any fields**:
   - Change title
   - Update description
   - Adjust sort order
   - Toggle featured status
   - Change shoot type
5. **Click "Save Changes"**

### Changing Gallery Order

To reorder galleries on your portfolio page:

1. Edit each gallery's **Sort Order** field
2. Lower numbers appear first
3. Use increments of 10 (0, 10, 20) for easy reordering

**Example**:
- Featured wedding gallery: Sort Order = 0
- Recent portrait work: Sort Order = 10
- Older work: Sort Order = 20

### Setting a Cover Image

The cover image is the main photo shown on the gallery card:

1. Edit the gallery
2. Under **Cover Image**, select from uploaded images
3. Choose your best/most representative photo
4. Save changes

**Tip**: Upload images first, then set the cover image.

## Uploading Images

### Step-by-Step Upload

1. **Click "Upload"** in sidebar
2. **Select Gallery** from dropdown
   - Choose which gallery to add images to
3. **Add Images**:
   - **Drag and drop** images onto the upload area
   - OR **Click** to browse and select files
4. **Upload Multiple Images**:
   - Select multiple files at once
   - They'll upload sequentially
5. **Wait for Processing**:
   - Images are optimized automatically
   - Progress indicator shows upload status
6. **View Uploaded Images**:
   - See thumbnails of uploaded images
   - Images appear in your gallery immediately

### Image Requirements

**Supported Formats**:
- JPEG (.jpg, .jpeg)
- PNG (.png)
- WebP (.webp)

**File Size**:
- No hard limit, but smaller files upload faster
- Images are automatically optimized

**Automatic Processing**:
Your images are automatically:
- Resized to maximum 2400px (preserves quality for large screens)
- Converted to WebP format (smaller file size, faster loading)
- Compressed at 85% quality (great visual quality, optimized size)

### Organizing Images in Gallery

After uploading, you can:

1. **Reorder Images**:
   - Edit image details
   - Change **Sort Order** field
   - Lower numbers appear first

2. **Add Alt Text** (Recommended):
   - Helpful for accessibility
   - Improves SEO
   - Example: "Bride and groom walking on beach at sunset"

3. **Delete Images**:
   - Find the image in your gallery
   - Click delete icon
   - Confirm deletion

### Best Practices for Images

**Selection**:
- Choose your absolute best work (10-30 images per gallery)
- Tell a story with your image sequence
- Include variety (details, wide shots, candids, posed)

**Image Order**:
- Start with a strong, attention-grabbing image
- Build a narrative flow
- End with a memorable shot

**Quality Over Quantity**:
- Better to have 15 amazing photos than 50 mediocre ones
- Curate ruthlessly
- Update galleries to remove weaker images

## Deleting a Gallery

### Before Deleting

**Warning**: Deleting a gallery also deletes all images in it. This cannot be undone.

**Alternative**: Instead of deleting, consider:
- Unmarking as "Featured" to hide from homepage
- Updating the sort order to move it down the list

### How to Delete

1. Go to **Galleries**
2. Find the gallery to delete
3. Click **Delete** icon or button
4. **Confirm** the deletion
5. Gallery and all its images are removed

## Managing Featured Galleries

Featured galleries appear on your homepage, making them highly visible to visitors.

### How Many to Feature?

**Recommended**: 3-6 galleries
- Too few: Homepage looks sparse
- Too many: Overwhelming for visitors

### Which Galleries to Feature?

Feature galleries that:
- Showcase your best work
- Represent different styles/services
- Appeal to your target clients
- Are recent and relevant

### Seasonal Updates

Update featured galleries periodically:
- **Spring/Summer**: Beach weddings, outdoor portraits
- **Fall/Winter**: Cozy indoor sessions, holiday photos
- **Throughout Year**: Mix recent and evergreen work

## Viewing Your Live Portfolio

To see how your portfolio appears to visitors:

1. **Click your site logo** (returns to public homepage)
2. **Click "Portfolio"** in main navigation
3. **Browse galleries** as a client would see them
4. **Click a gallery** to see the full collection with lightbox viewer

### Portfolio Features (Client View)

**Gallery Grid**:
- Cards showing cover image, title, and description
- Filter by shoot type
- Click to view full gallery

**Gallery Page**:
- All images in a responsive grid
- Click any image to open lightbox
- Navigate with arrow keys or on-screen arrows
- View full-size images

## Tips for a Great Portfolio

### Curation

- **Quality Over Quantity**: Show only your best work
- **Consistency**: Maintain consistent editing style
- **Variety**: Show range within your specialty
- **Update Regularly**: Add new work, remove older pieces

### Organization

- **Clear Naming**: Make it obvious what each gallery contains
- **Logical Grouping**: Group by type, season, or style
- **Strategic Ordering**: Best work first

### Presentation

- **Strong Opening Images**: First image in each gallery should wow
- **Tell Stories**: Arrange images to show beginning, middle, end
- **Cover Images**: Choose eye-catching covers that represent the gallery

### Maintenance

- **Monthly Review**: Check that featured galleries are still your best
- **Seasonal Refresh**: Update based on what you're booking
- **Client Feedback**: Pay attention to which galleries get the most interest

## Common Questions

**Q: How many galleries should I have?**
A: 10-20 is a good range. Enough to show variety, not so many it's overwhelming.

**Q: How many images per gallery?**
A: 15-30 images is ideal. Enough to tell the story, not so many it's tedious to browse.

**Q: Should I show all my work?**
A: No! Only show work you want to book more of. Quality and curation matter.

**Q: Can I password-protect a gallery?**
A: Public portfolio galleries are not password-protected. For private client delivery, use Client Galleries instead (see [Client Galleries Guide](./client-galleries.md)).

**Q: How do I rename a gallery?**
A: Edit the gallery and change the Title field. The slug will remain the same unless you manually change it (changing slug will break existing links).

**Q: What if I upload the wrong image?**
A: Simply delete it from the gallery and upload the correct one.

**Q: Can I bulk upload images?**
A: Yes! Select multiple images at once when uploading. They'll process one after another.
