  <name>Task 1: Apply command — fetch, write, install, track</name>
  <files>packages/blink-cli/src/commands/apply.ts, packages/blink-cli/tests/commands/apply.test.ts</files>
  <behavior>
    - apply <slug> fetches index to find artifact type from slug, then fetches full artifact data
    - apply <slug> writes each artifact file to cwd-relative path, creating directories as needed
    - apply <slug> prompts to overwrite if file already exists and is not blink-managed (consola confirm)
    - apply <slug> with --yes or non-TTY skips overwrite prompt (auto-yes)
    - apply <slug> when slug already in manifest warns "already installed" and suggests blink update, exits
    - apply <slug> auto-initializes .blink/ if manifest doesn't exist (creates manifest + .gitignore entry silently)
    - apply <slug> with devDependencies prompts to install them, showing package list
    - apply <slug> runs detected PM install command via child_process.execSync when deps confirmed
    - apply <slug> adds ManifestEntry with slug, name, type, version, scope='project', installedAt=ISO string, files with checksums
    - apply --dry-run shows [dry run] header, then [write], [install], [manifest] labeled actions, ends with "No changes made."
    - apply --dry-run does NOT write files, install deps, or update manifest
    - apply handles ARTIFACT_NOT_FOUND (slug not in index) with clear error message
    - apply handles network errors with retry exhaustion message
    - Checksum is computed from the exact content string written to disk (per research pitfall 5)
  </behavior>
  <action>
    Create `src/commands/apply.ts`:
    - ABOUTME: Fetches an artifact from the registry and applies it to the project
    - ABOUTME: Handles file writing, dependency installation, and manifest tracking
    - Import defineCommand from citty, consola from consola, pc from picocolors
    - Import writeFile/mkdir/readFile/stat from node:fs/promises, join/dirname from node:path, execSync from node:child_process
    - Import fetchIndex, fetchArtifact from '@/registry'
    - Import readManifest, writeManifest, createEmptyManifest, addManifestEntry, checksum, BLINK_DIR from '@/manifest'
    - Import detectPackageManager from '@/pm'
    - Import formatActionLabel, formatDryRunHeader from '@/output'

    defineCommand:
    - meta: { name: 'apply', description: 'Apply a config, skill, or hook from the registry' }
    - args: slug (positional, required), --dry-run (boolean), --yes / -y (boolean)
    - run({ args }):

    1. **Resolve artifact:**
       - const skipPrompt = args.yes || !process.stdout.isTTY
       - const dryRun = args['dry-run']
       - Fetch index, find item by slug. If not found: consola.error(`Artifact "${slug}" not found in registry.`), exit(1)
       - Fetch full artifact: fetchArtifact(item.type, item.slug)

    2. **Check already installed:**
       - const cwd = process.cwd()
       - let manifest = await readManifest(cwd)
       - If manifest and manifest.items.find(i => i.slug === slug): consola.warn(`${pc.bold(slug)} is already installed. Use ${pc.dim('blink update')} to update.`), return

    3. **Dry-run header:**
       - If dryRun: consola.log(formatDryRunHeader() + ` Previewing apply ${pc.bold(artifact.name)}`)

    4. **Auto-init:**
       - If !manifest: manifest = createEmptyManifest(), if !dryRun: await writeManifest(cwd, manifest) + add .gitignore entry (reuse logic from init or inline helper)

    5. **Write files:**
       - const fileEntries: ManifestFileEntry[] = []
       - For each file in artifact.files:
         - const destPath = join(cwd, file.path)
         - Check if file exists (stat). If exists:
           - If dryRun: consola.log(`${formatActionLabel('write')} ${pc.dim(file.path)} ${pc.yellow('(exists, would overwrite)')}`), continue to next step
           - If !skipPrompt: prompt "file.path already exists. Overwrite?" — if cancelled/no, skip file
         - If dryRun: consola.log(`${formatActionLabel('write')} ${pc.dim(file.path)}`), push to fileEntries with checksum, continue
         - await mkdir(dirname(destPath), { recursive: true })
         - await writeFile(destPath, file.content)
         - consola.success(`${formatActionLabel('write')} ${pc.dim(file.path)}`)
         - fileEntries.push({ path: file.path, checksum: checksum(file.content), merge: file.merge })

    6. **Install dependencies:**
       - If artifact.devDependencies and Object.keys > 0:
         - const pm = detectPackageManager(cwd)
         - const deps = Object.entries(artifact.devDependencies).map(([k,v]) => `${k}@${v}`)
         - If dryRun: consola.log(`${formatActionLabel('install')} ${deps.join(', ')} via ${pm.name}`), skip
         - Else:
           - If !skipPrompt: prompt "Install dev dependencies? {deps list}" — if no, skip
           - const cmd = pm.installDev(deps)
           - consola.info(`Installing dependencies via ${pc.bold(pm.name)}...`)
           - try execSync(cmd, { cwd, stdio: 'inherit' }) catch: consola.error('Dependency installation failed. Run manually: ' + cmd)

    7. **Update manifest:**
       - const entry: ManifestEntry = { slug: artifact.slug, name: artifact.name, type: artifact.type, version: artifact.version, scope: 'project', installedAt: new Date().toISOString(), files: fileEntries }
       - If dryRun: consola.log(`${formatActionLabel('manifest')} Track ${pc.bold(artifact.name)} in manifest`), consola.log(pc.dim('\nNo changes made.')), return
       - manifest = addManifestEntry(manifest, entry)
       - await writeManifest(cwd, manifest)
       - consola.success(`Applied ${pc.bold(artifact.name)} ${pc.dim(artifact.version)}`)

    For helper function `confirmAction(message, skipPrompt)`:
    - If skipPrompt: return true
    - const result = await consola.prompt(message, { type: 'confirm' })
    - If typeof result === 'symbol': consola.info('Cancelled.'), process.exit(0)
    - return result

    Tests should mock: global fetch (for registry calls), node:child_process execSync (for PM install), and use tmp directories for real FS operations. Test scenarios:
    - Happy path: apply writes files + manifest
    - Already installed: warns and skips
    - File conflict with --yes: overwrites without prompt
    - Dry-run: no files written, correct output labels
    - Non-TTY: no prompts
    - Unknown slug: error message
    - Auto-init: creates manifest when missing
    - DevDependencies: runs install command
