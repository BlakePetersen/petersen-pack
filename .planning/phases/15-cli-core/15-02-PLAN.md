    - init does not duplicate .blink/ entry if already in .gitignore

    - init shows detected package manager name during output
    - init with --yes does not prompt (init has no prompts currently, but should accept the flag for consistency)
  </behavior>
  <action>
    Create `src/commands/init.ts`:
    - ABOUTME comments: Initializes blink tracking in a project
    - Import defineCommand from citty, consola from consola, pc from picocolors
    - Import readManifest, writeManifest, createEmptyManifest, BLINK_DIR from '@/manifest'
    - Import detectPackageManager from '@/pm'
    - defineCommand with meta { name: 'init', description: 'Initialize blink in this project' }
    - No required args. Optional --yes boolean.
    - run():
      1. const cwd = process.cwd()
      2. const existing = await readManifest(cwd)
      3. If existing: consola.info(`blink is already initialized (${existing.items.length} items tracked)`), return
      4. const manifest = createEmptyManifest()
      5. await writeManifest(cwd, manifest)
      6. await addToGitignore(cwd) — helper function
      7. const pm = detectPackageManager(cwd)
      8. consola.success(`Initialized blink in ${pc.dim('.blink/')}`)
      9. consola.info(`Detected package manager: ${pc.bold(pm.name)}`)
    - addToGitignore(cwd): read .gitignore (or empty string), check if '.blink/' already present, if not: ensure trailing newline + append '.blink/\n', write back
