  dependencies: z.array(SlugSchema).optional(),

})

| T-28-01-01 | Tampering | scaffold slug → file path | mitigate | Validate slug against SlugSchema regex (`^[a-z0-9]+(-[a-z0-9]+)*$`) before constructing file paths; reject slugs containing `..`, `/` prefix, or path separators |
| T-28-01-02 | Tampering | scaffold → YAML injection | accept | Slug is validated; title derived from slug (no user free-text in frontmatter); description is a placeholder string — no injection vector |
| T-28-01-03 | Denial of Service | --force overwrites | accept | --force is explicit opt-in; default behavior refuses overwrite. User intent is clear. |
