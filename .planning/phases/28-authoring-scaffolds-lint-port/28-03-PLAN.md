    ```typescript
    // ABOUTME: Pure transform functions for converting Obsidian markdown to MDX.
    // ABOUTME: Handles callout→component, wikilink→cross-ref, frontmatter normalization, dataview strip.
    ```

    1. `transformCallouts(content: string): string`:
       - Regex to match callout blocks: `/^> \[!(note|tip|warning|important|info|[a-z]+)\].*?\n((?:> .*\n?)*)/gm`
       - Map callout type per D-08:
         - `note`, `tip` → `<AuthorNote>\n{body}\n</AuthorNote>`
         - `warning`, `important` → `<DecisionRationale>\n{body}\n</DecisionRationale>`
         - `info` → keep as plain blockquote `> {body}`
         - unknown → `<AuthorNote>\n{body}\n</AuthorNote>` (fallback)
       - Strip `> ` prefix from each body line
       - Callout title line (text after `[!type]`) becomes the first line of body if present

    2. `transformWikilinks(content: string, contentSlugs: Map<string, { title: string; href: string }>): string`:
       - Regex: `/\[\[([^\]|]+)(?:\|([^\]]+))?\]\]/g`
       - For each match:
         - Lookup bareSlug = match[1] against contentSlugs map
         - If found: `[${displayText || entry.title}](${entry.href})`
         - If not found: `${displayText || bareSlug}{/* TODO: resolve wikilink */}`

    3. `transformFrontmatter(data: Record<string, unknown>): { mapped: Record<string, unknown>; unknownComment: string }`:
       - Known keys that map directly: `title`, `description`, `tags`
       - Additional mapping: `aliases` → ignored (Obsidian-only), `date` → `updated_context` (if ISO-parseable)
       - Add defaults for dxFields not present: `applies_to: []`, `draft: true`
       - Unknown keys: format as `{/* Obsidian meta (review + delete): key1: val1, key2: val2 */}` comment string
       - Return both the mapped frontmatter object and the unknown-keys comment

    4. `transformDataviewBlocks(content: string): string`:
       - Regex: `/```dataview\n[\s\S]*?```/g` → replace with empty string
       - Trim resulting double blank lines to single blank lines
  </action>

    ```typescript
    // ABOUTME: Stage and commit workflow for the Obsidian port pipeline.
    // ABOUTME: Stage applies transforms to .obsidian-port-staging/; commit moves to content/.
    ```

    1. `STAGING_DIR` constant: `.obsidian-port-staging`

    2. `stageEntry(options: StageOptions): Promise<StageResult>`:
       ```typescript
       interface StageOptions {
         inputDir: string          // directory containing exported Obsidian markdown
         slugFilter?: string       // optional: stage only this slug
         contentRoot: string       // path to content/ for wikilink resolution
       }
       interface StageResult {
         staged: Array<{ slug: string; path: string }>
       }
       ```
       - Discover `.md` files in inputDir
       - For each file:
         1. Read content
         2. Parse frontmatter with `gray-matter`
         3. `transformFrontmatter(data)` → mapped frontmatter + unknown comment

         9. `atomicWrite(path.join(STAGING_DIR, slug + '.mdx'), content)`

       ```typescript
       interface CommitOptions {
         slug: string
         collection: string       // e.g. 'skills'
         contentRoot: string
         stagingDir?: string       // defaults to STAGING_DIR
       }
       ```
       - Read `.obsidian-port-staging/<slug>.mdx`

       - If `.obsidian-port-staging/<slug>.artifact.md` exists, move that too
       - Remove staged files after successful commit

       - Used by stageEntry for wikilink resolution
