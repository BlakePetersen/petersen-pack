    Test approach (RECOMMENDED -- simpler, faster, more reliable than full Velite fixture):
    - Import `DxFrontmatterSchema` from 'blink-registry'
    - Import `generateScaffold` from blink-cli's scaffold generator
    - For each collection:
      1. Generate scaffold to temp directory
      2. Read the generated .mdx file
      3. Parse frontmatter with gray-matter
      4. Validate against DxFrontmatterSchema via `safeParse`
      5. Assert parse succeeds
      6. For non-guide collections: verify .artifact.md exists and has valid artifact frontmatter

    This approach tests SCAFFOLD-05 ("scaffold each collection, then assert schema validation") without needing a full Velite build. The schema is the same source of truth.

    Test cases:
    ```typescript
    describe('scaffold round-trip', () => {
      const collections = ['skill', 'config', 'hook', 'guide'] as const

      test.each(collections)('blink scaffold %s produces schema-valid MDX', async (collection) => {
        const result = await generateScaffold({
          collection,
          slug: `test-roundtrip-${collection}`,
          contentRoot: tmpDir,
          dryRun: false,
          force: false,
        })

        const plural = collection + 's'
        const mdxPath = path.join(tmpDir, plural, `test-roundtrip-${collection}.mdx`)
        expect(fs.existsSync(mdxPath)).toBe(true)

        const raw = fs.readFileSync(mdxPath, 'utf-8')
        const { data } = matter(raw)
        const parsed = DxFrontmatterSchema.safeParse(data)
        expect(parsed.success).toBe(true)
      })

      test.each(['skill', 'config', 'hook'] as const)('blink scaffold %s produces companion .artifact.md', async (collection) => {
        const artifactPath = path.join(tmpDir, collection + 's', `test-roundtrip-${collection}.artifact.md`)
        expect(fs.existsSync(artifactPath)).toBe(true)
      })

      test('blink scaffold guide does NOT produce .artifact.md', async () => {
        const artifactPath = path.join(tmpDir, 'guides', 'test-roundtrip-guide.artifact.md')
        expect(fs.existsSync(artifactPath)).toBe(false)
      })
    })
    ```

    Temp directory setup in beforeAll/afterAll:
    - `tmpDir = mkdtempSync(join(tmpdir(), 'scaffold-roundtrip-'))`
    - Create collection subdirectories: `skills/`, `configs/`, `hooks/`, `guides/`
    - Clean up in afterAll
