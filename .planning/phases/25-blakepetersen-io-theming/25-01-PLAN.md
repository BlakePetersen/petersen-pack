# Plan 25-01: Theming Audit and Cleanup

## Goal

Verify Phase 25 success criterion #4 ("All existing pages render correctly in both light and dark modes with no hardcoded color artifacts") by replacing real token-system violations and documenting intentional theme-static cases.

## Context

ThemeProvider, theme-toggle, FOUT prevention, and artax-ui token import are all already wired in `apps/blakepetersen.io/` (see `25-CONTEXT.md` decisions). This plan audits the existing source for color literals and resolves each one.

## Audit Findings (pre-classified)

A `grep` over `apps/blakepetersen.io/src/**` for `#hex`, `rgb()`, `hsl()`, named CSS colors, and Tailwind palette utilities returned 13 hits across 12 files. Triage:

### Real violations (replace with semantic tokens)
| File | Line | Current | Replacement | Why |
|------|------|---------|-------------|-----|
| `src/components/dependency-graph.tsx` | 15 | `text-zinc-500` | `text-muted-foreground` | Subdued caption text; semantic token already covers it |
| `src/components/dx-content-layout.tsx` | 71 | `text-zinc-500` | `text-muted-foreground` | Same caption pattern; same replacement |

### Theme-static (legitimate, add `// theme-static:` comment)
| File | Lines | Reason |
|------|-------|--------|
| `src/components/command-palette.tsx` | 155 | Dialog overlay `bg-black/80` — modal scrim is conventionally a dark semi-transparent layer in both light and dark modes (artax-ui has no overlay token) |
| `src/components/sidebar-drawer.tsx` | 36 | Same Dialog overlay pattern |
| `src/app/dev/components/page.tsx` | 44–45 | Dev-only page wrapper (`bg-neutral-500`, `text-white`); intentionally a fixed mid-gray so light + dark theme columns render side-by-side for comparison |
| `src/lib/og-image.tsx` | 34, 37, 45, 53, 64, 78, 90 | Open Graph image generation — runs server-side, ships PNG; theme-independent by design |
| `src/lib/shiki-theme.ts` | entire `terminalTheme` | Syntax highlighting uses a single dark theme in both light and dark site modes (terminal aesthetic by intent); cross-theme syntax theme is deferred future work |
| `src/lib/graph.ts` | 236, 246, 254, 263, 267, 271 | SVG dependency-graph rendered server-side to a string and shipped as image; theme-independent |
| `src/lib/collection-registry.ts` | 30, 42, 54, 66, 78 | Per-collection brand accent colors used as section indicator dots in the sidebar; intentionally consistent across themes |
| `src/lib/navigation.ts` | 57 | "Project" section accent color (`#6B7280`); same brand-accent pattern as collection-registry |

### False positive
| File | Line | Match |
|------|------|-------|
| `src/components/report-problem-link.tsx` | 31 | `&#8599;` is the HTML entity for ↗ — not a color literal |
